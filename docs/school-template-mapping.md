# 学校论文模板迁移清单

本文件用于把当前 BIMER 答辩版论文迁移到学校最终模板。学校正式模板尚未提供，
因此这里只固定内容映射、待填字段和验收步骤，不猜测学校名称、专业格式或版式参数。

## 1. 封面与声明待填字段

收到学校模板后，逐项从教务信息核对并填写：

- 学校与学院名称；
- 专业、班级与培养层次；
- 学生姓名与学号；
- 指导教师姓名、职称与所在单位；
- 论文完成日期、提交日期与答辩日期；
- 中文题目与英文题目；
- 原创性声明、授权声明及签名日期。

固定论文题目：

> 基于质量感知与对话上下文建模的中英文多模态情感识别研究与系统实现

建议英文题目：

> Research and Implementation of Chinese-English Multimodal Emotion
> Recognition Based on Quality Awareness and Dialogue Context Modeling

## 3. 必须保持一致的冻结事实

- 正式部署模型为 V2 `quality_lagf` seed 42。
- V2 双语平均 weighted-F1 为 `60.148% ± 1.124%`。
- 相对 Early MLP 提升 `1.493` 个百分点，配对 cluster bootstrap
  95% CI 为 `[0.669, 2.200]`。
- 得到统计支持的核心贡献是对话上下文与模态随机屏蔽。
- 质量机制只主张对部分视频退化具有针对性收益。
- 语言嵌入未获支持；V3、V4均为遵守预声明停止规则的探索结果。
- V5无论成功或失败均属于事后探索，不替换V2答辩部署模型。
- 外部20段测试在两名真人独立标注前保持
  `blocked_human_annotation`，不得填写kappa或模型指标。

## 4. 一键迁移前的替换清单

在收到学校模板后，只替换以下模板控制项，不改研究数字：

1. 页面大小、页边距、装订线、页眉和页脚；
2. 中英文字体、字号、行距和段前段后；
3. 章节编号、图表编号、公式编号与题注格式；
4. 目录层级、页码起始位置和奇偶页规则；
5. 参考文献样式、脚注/尾注和附录编号；
6. 封面、声明、任务书、评阅页等学校专用前置页。

## 5. 最终验收

- 学校模板字段全部来自真实教务信息，无占位符。
- 中文摘要、英文摘要、论文正文、PPT和README中的模型版本与指标一致。
- 图、表、公式、参考文献均可交叉引用，目录页码已更新。
- 所有页面渲染后无重叠、截断、孤行或大面积异常空白。
- Word、PDF页数与目录一致；PDF字体可嵌入且中文字符正常。
- V5结论、系统级swap结论和外测状态与机器可读证据一致。
