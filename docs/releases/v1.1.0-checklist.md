# BIMER v1.1.0 Release Checklist

The release is allowed only after every mandatory item below is checked against
the final commit. V2 remains the deployed and confirmatory model.

## Mandatory engineering gates

- [x] Package, citation, README, model card, and deployment metadata use
  `1.1.0`.
- [x] `uv sync --extra dev --extra inference --frozen` succeeds in a clean
  clone.
- [x] The clean-clone suite passes 491 tests with at least 85% total coverage.
- [x] Ruff, the expanded Mypy scope, the public-tree policy, and dependency
  audit pass.
- [x] The public API and legacy CLI commands remain compatible.
- [x] Runtime, experiment protocol, and public/private evidence ADRs exist.
- [ ] GitHub CI passes on the final release commit.
- [ ] The draft pull request is marked ready and merged to `main`.

## Research gates

- [x] V2 reports and deployment hashes remain unchanged.
- [x] V3 and V4 remain explicitly exploratory and are not deployed.
- [ ] V5 validation decision is frozen and archived with SHA-256.
- [ ] If V5 passes validation, its one-time exploratory test and
  `TEST_EVALUATED` marker are archived; if it fails, no official test is run.
- [x] External evaluation remains `blocked_human_annotation` until two real,
  independent annotation packs are complete.

## Defense gates

- [x] Offline doctor, bilingual M2 latency, memory, export, and no-face
  behavior have evidence.
- [x] The backup recording and source-locked Chinese/English samples exist.
- [ ] Clean-login system swap acceptance passes, or the remaining limitation
  is explicitly retained in the thesis and defense deck.
- [ ] Thesis DOCX/PDF and PPTX are regenerated from the final evidence and
  visually inspected.
- [ ] The canonical private defense package is rebuilt, hashed, verified
  offline, and referenced by `output/private-defense/CURRENT.txt`.

## Publication gates

- [x] The public tree contains no restricted media, features, weights, private
  annotations, or per-sample restricted predictions.
- [ ] `RESULTS.md`, `MODEL_CARD.md`, the thesis, and the defense deck state the
  same V5 and external-evaluation conclusions.
- [ ] Tag `v1.1.0` points at the merge commit that passed CI.
- [ ] The GitHub Release describes V2 as the deployment model and V5 as a
  bounded exploratory study.
