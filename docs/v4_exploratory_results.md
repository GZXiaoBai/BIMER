# BIMER V4 探索性实验报告

## 1. 实验定位与证据边界

V4 是在 V2 确认性实验完成后开展的事后探索性改进。V2 `quality_lagf` 仍是论文确认性主模型和演示系统部署模型。V4 的全部结构、阈值和停止规则均先在验证集协议中冻结；由于正式三随机种子结果没有通过全部预声明门槛，V4 未访问 MELD 或 EmotionTalk 官方测试集，也未替换 V2。

## 2. 分阶段筛选结果

### 2.1 V4-A：上下文自适应与类别原型

V4-A 的上下文门、类别原型及其组合均未通过 seed 42 验证筛选。最佳候选为仅使用上下文门的结构，但相对筛选基线：

- 双语 weighted-F1 仅提高约 0.412 个百分点，未达到 1.0 个百分点门槛。
- 双语 macro-F1 下降约 0.805 个百分点。
- `fear、disgust、sadness` 平均 F1 下降约 2.081 个百分点。

因此，类别原型没有进入后续正式实验；正式 V4 的原型损失权重为 0。

### 2.2 V4-B：条件触发文本 LoRA

按照预声明规则，V4-A 失败后才启动 XLM-RoBERTa-base 的 LoRA 文本适配。两个学习率候选均通过 seed 42 验证筛选：

| 学习率 | 双语 weighted-F1 增量 | 双语 macro-F1 增量 | 少数类平均 F1 增量 | 最差单数据集 weighted-F1 增量 |
|---:|---:|---:|---:|---:|
| `1e-4` | +2.339 | +2.214 | +2.035 | +1.305 |
| `2e-4` | +2.231 | +2.248 | +2.417 | +0.820 |

按预声明的平衡得分选用 `1e-4`。后续音频、视觉和质量特征均复用既有缓存，只重新生成适配后的文本特征。

## 3. 三随机种子正式验证结果

正式实验使用随机种子 `42、123、2026`，以下均为验证集结果，标准差使用 `ddof=1`。

| 数据集 | weighted-F1 | macro-F1 |
|---|---:|---:|
| MELD | 62.179% ± 0.834% | 47.369% ± 1.734% |
| EmotionTalk | 66.932% ± 0.111% | 62.191% ± 0.333% |
| 双语平均 | **64.556% ± 0.409%** | **54.780% ± 0.936%** |

三个正式模型进行等权概率平均后，验证集双语平均 weighted-F1 为 65.241%，macro-F1 为 55.183%。该集成结果只用于验证分析，没有进入系统部署决策。

## 4. 预声明稳定性判定

| 判定项 | 实际结果 | 门槛 | 是否通过 |
|---|---:|---:|:---:|
| 双语 weighted-F1 增量 | +2.641 个百分点 | ≥ +1.0 | 是 |
| 双语 macro-F1 增量 | +2.089 个百分点 | ≥ +0.8 | 是 |
| 最差单数据集 weighted-F1 增量 | +1.396 个百分点 | ≥ -0.3 | 是 |
| `fear、disgust、sadness` 平均 F1 增量 | +1.329 个百分点 | ≥ +1.5 | **否** |

V4 距离少数类门槛还差 0.171 个百分点，因此正式判定为 `formal_stable=false`。按照实验协议，项目在此停止 V4 追分，不运行官方测试，不以验证集结果替换 V2 的确认性结果。

## 5. 消融解释

- 正式模型中的自适应上下文门均值接近 0.99，基本退化为始终启用上下文。
- 去除上下文门后的双语 weighted-F1 为 64.522% ± 0.536%，与完整 V4 的 64.556% ± 0.409% 几乎相同；macro-F1 还略高于完整 V4。
- 类别原型在 V4-A 筛选阶段已失败，正式结构中的原型权重为 0，因此“去除原型”与完整模型等价，不能作为原型有效性的证据。
- V4 的主要收益来自 LoRA 文本适配，而不是上下文门或类别原型。

## 6. 最终结论

V4 达到了探索性模型性能目标，说明冻结多模态主干并轻量适配跨语言文本编码器具有明显潜力；但它没有完整通过预声明的少数类稳定性门槛，且两个拟议的新结构创新没有获得消融支持。因此：

1. V2 `quality_lagf` 继续作为论文确认性主结果与演示系统模型。
2. V4 作为“高性能但未完全通过门槛”的探索性结果写入论文，不宣称其官方测试性能。
3. 论文创新主张仍限定为对话上下文、模态随机屏蔽，以及质量机制对特定视频退化的针对性收益。
4. V4 的价值主要是给出严谨的失败边界：性能提升不等于结构创新获得支持，验证集高分也不能替代预声明协议与官方测试保护。
